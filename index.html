You download this once. Inside the tool, open About → Check for updates and it pulls the latest signed version, verifies it, and updates itself — no reinstalling, no re-downloading.

Get started in 3 steps

About two minutes from download to first test.

1
Download & unzipRight-click the file → Extract All.
2
Open the folderGo into the Application folder inside.
3
Run the toolDouble-click Packet_SysTest_Tool.exe.
Good to know After you unzip, the folder looks like this. Your Excel blocks file must sit next to Packet_SysTest_Tool.exe inside Application so the tool can load it:
PacketSysTest-Setup ├─ Updater.exe └─ Application ├─ Packet_SysTest_Tool.exe ├─ _internal ├─ version.json └─ Packet_SysTest_Blocks.xlsx ← keep the Excel here, beside the tool
Keep Updater.exe next to the Application folder — it's what performs updates.
On first launch, Windows SmartScreen may warn about an unknown publisher: click More info → Run anyway.
